# IQOO LAUNCHER

IQOO Launcher — Project Velocity | Premium Android Launcher

IQOO LAUNCHER is an original Kotlin and Jetpack Compose launcher project. The Phase 2 candidate is a daily-use shell with a stable asynchronous app drawer, local search, dock, PULSE, swipe surfaces, a public-API control centre and the supported Android HOME-role flow.

See `docs/ARCHITECTURE.md`, `docs/RESEARCH.md`, `docs/PERMISSIONS.md`, and `docs/DEVICE-TESTING.md` for current boundaries. GitHub Actions runs unit tests, lint and a debug build; this project does not generate local APKs during development. The real notification shade/Quick Settings remain OS-owned and are not replaceable by a normal third-party launcher.
