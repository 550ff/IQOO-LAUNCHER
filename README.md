# IQOO LAUNCHER

IQOO Launcher — Project Velocity | Premium Android Launcher

IQOO LAUNCHER is an original Kotlin and Jetpack Compose launcher project. The current candidate implements the runtime device profile, an event-driven charging capsule, app discovery/search/launch, and a shared lightweight glass/motion foundation.

See `docs/ARCHITECTURE.md`, `docs/RESEARCH.md`, `docs/PERMISSIONS.md`, and `docs/DEVICE-TESTING.md` for current boundaries. GitHub Actions runs unit tests, lint and a debug build; this project does not generate local APKs during development.
